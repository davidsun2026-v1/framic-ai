# AGENTS.md — Framic AI (Next.js / React)

## Project summary
Framic AI is a creator video-content web app with real-time generation workflows:
- Text → Image
- Text → Video
- Real-time / streaming UX where applicable

## How to work in this repo (for Codex)
- Make small, reviewable changes; avoid repo-wide refactors unless asked.
- Follow existing patterns for routing, data fetching, state, and styling.
- Keep the “generation path” low-latency (avoid blocking server routes/UI on long work).

## Security & privacy
- Never commit secrets (API keys, tokens, credentials).
- Use environment variables and the repo’s existing config patterns.
- Don’t log prompts, uploaded media, or generated outputs unless the repo already has an approved telemetry pattern.

## Build / run / test
- Use the package manager and scripts defined in `package.json`.
- After changes, run the smallest relevant checks (tests + lint/typecheck if configured).

## Code quality conventions
- Prefer TypeScript if the repo uses it; otherwise keep to the current JS style.
- Add/update tests for new behavior when the repo has a test framework in place.
- Keep API boundaries clear (client vs server; shared types in a shared module if present).

## Real-time generation rules
- Prefer streaming/async patterns already used in the codebase.
- Make job execution idempotent; retries should not duplicate work.
- Surface errors clearly to the UI (actionable messages, safe retries).

## “Done when”
A change is done when:
- Feature works end-to-end for the described user flow
- Relevant tests pass (and lint/typecheck pass if present)
- Any new env vars, endpoints, or config are documented

## Code Review Rules
- Flag changes that increase latency in generation/streaming paths.
- Flag missing authz/validation on any server action.
- Flag potential retry/duplication bugs (double charges, duplicate jobs, duplicate uploads).
