# Dashboard

## Purpose
Give authenticated users a truthful operational view of their account and creation activity.

## Scope
Current credit balance, subscription entitlement, recent generations, generation status, recent assets, and relevant usage information.

## Rules
All data is user-scoped. Dashboard values must come from authoritative records, not duplicated client state.

## Acceptance
The dashboard reflects current account state and links users to generation history, assets, credits, and subscription management.

## Non-goals
Administrative analytics and marketplace functionality.
