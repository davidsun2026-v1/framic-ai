## System Requirements

### Minimum Requirements
- **OS**: macOS 12+, Ubuntu 20+, Windows 10+ (WSL2)
- **Node.js**: 18.17+ or Bun 1.0+
- **RAM**: 8GB minimum (16GB recommended)
- **Disk**: 10GB free space
- **Docker**: 20.10+ with Docker Compose 2.0+

### Recommended Setup
- **Node.js**: 20 LTS
- **Bun**: 1.0+ (faster alternative to npm)
- **RAM**: 16GB+
- **SSD**: Yes (for better performance)

## Pre-Installation

### 1. Install Node.js (if not using Bun)

#### macOS
```bash
# Using Homebrew
brew install node@20
brew link node@20 --force

# Verify installation
node --version  # Should be v20.x.x
npm --version   # Should be 10.x.x
```

#### Linux (Ubuntu/Debian)
```bash
# Using NodeSource repository
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# Verify installation
node --version
npm --version
```

#### Windows
```powershell
# Using Chocolatey
choco install nodejs

# Or download from https://nodejs.org/
# Verify in PowerShell
node --version
npm --version
```

### 2. Install Bun (Optional but Recommended)

Bun is 3-4x faster than npm for installation and running scripts.

```bash
# macOS & Linux
curl -fsSL https://bun.sh/install | bash

# Windows (PowerShell)
powershell -c "irm bun.sh/install.ps1 | iex"

# Verify installation
bun --version
```

### 3. Install Docker

#### macOS
```bash
# Using Homebrew
brew install docker docker-compose

# Or download Docker Desktop
# https://www.docker.com/products/docker-desktop
```

#### Linux
```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install docker.io docker-compose

# Add user to docker group (avoid sudo)
sudo usermod -aG docker $USER
newgrp docker
```

#### Windows
- Download [Docker Desktop for Windows](https://www.docker.com/products/docker-desktop)
- Install and restart
- Enable WSL2 backend in settings

**Verify Docker:**
```bash
docker --version
docker-compose --version
```

### 4. Install Git

```bash
# macOS
brew install git

# Linux
sudo apt-get install git

# Windows - Download from https://git-scm.com/

# Verify
git --version
```

### 5. Configure Git

```bash
# Set your identity (required for commits)
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

# (Optional) Configure SSH key for GitHub
ssh-keygen -t ed25519 -C "your.email@example.com"
# Add public key to GitHub: https://github.com/settings/ssh/new
```

## Environment Configuration

### 1. Create Local Environment File

```bash
# Copy the example file
cp .env.example .env.local
```

### 2. Edit `.env.local`

Open `.env.local` and configure with your credentials:

```bash
# ========================
# APPLICATION
# ========================
NODE_ENV=development
ENVIRONMENT=development

# ========================
# SUPABASE (Database)
# ========================
NEXT_PUBLIC_SUPABASE_URL=http://localhost:54321
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key-here

# For local development, use these defaults:
# URL: http://localhost:54321
# Keys will be generated by docker-compose

# ========================
# AUTHENTICATION
# ========================
JWT_SECRET=your-super-secret-jwt-key-min-32-chars
JWT_EXPIRY=7d

# ========================
# AI PROVIDERS
# ========================
REPLICATE_API_TOKEN=your-replicate-api-token
# Get from: https://replicate.com/account/api-tokens

# ========================
# PAYMENTS (Paystack)
# ========================
NEXT_PUBLIC_PAYSTACK_PUBLIC_KEY=your-paystack-public-key
PAYSTACK_SECRET_KEY=your-paystack-secret-key

# For testing, use Paystack test keys:
# https://dashboard.paystack.co/settings/developer

# ========================
# FILE STORAGE
# ========================
AWS_S3_BUCKET=framic-ai-dev
AWS_S3_REGION=us-east-1
AWS_ACCESS_KEY_ID=minioadmin
AWS_SECRET_ACCESS_KEY=minioadmin

# For local dev, use MinIO (included in docker-compose)
# Endpoint: http://localhost:9000

# ========================
# MONITORING & LOGGING
# ========================
SENTRY_DSN=your-sentry-dsn-for-error-tracking
SENTRY_AUTH_TOKEN=your-sentry-auth-token

# For development, you can skip Sentry initially

# ========================
# EMAIL
# ========================
SENDGRID_API_KEY=your-sendgrid-api-key
FROM_EMAIL=noreply@creatorosprod.com

# For development, you can use Resend or Mailgun

# ========================
# API CONFIGURATION
# ========================
NEXT_PUBLIC_API_URL=http://localhost:3000
API_SECRET=your-internal-api-secret

# ========================
# FEATURE FLAGS
# ========================
ENABLE_MARKETPLACE=false
ENABLE_VIDEO_GENERATION=false
ENABLE_TEAM_COLLABORATION=false
```

### 3. Generate Secrets

For secure random keys:

```bash
# Generate JWT secret (32+ characters)
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# Generate API secret
openssl rand -hex 32

# Or use online generator: https://www.uuidgenerator.net/
```

### 4. Verify Environment Setup

```bash
# Check if .env.local exists
ls -la .env.local

# Verify it's not committed (should be in .gitignore)
git status | grep .env.local
# Should show: ".env.local" (not in output = good, it's ignored)
```

## Database Setup

### 1. Start Supabase (Docker)

```bash
# Start all services (Supabase, MinIO, etc.)
docker-compose up -d

# Wait 30 seconds for services to fully initialize

# Verify services are running
docker-compose ps
```

**Expected output:**
```
NAME                      STATUS          PORTS
framic-ai-supabase       Up 30 seconds   5432->5432/tcp, 54321->54321/tcp
framic-ai-minio          Up 30 seconds   9000->9000/tcp, 9001->9001/tcp
framic-ai-redis          Up 30 seconds   6379->6379/tcp
```

### 2. Access Supabase Console

Open in browser: `http://localhost:54321`

**Default credentials:**
- Email: `supabase@example.com`
- Password: `password`

### 3. Run Database Migrations

```bash
# Run all pending migrations
bun run db:migrate
# OR
npm run db:migrate

# Expected output:
# ✓ Running migration: 001_create_users_table.sql
# ✓ Running migration: 002_create_subscriptions_table.sql
# ... (more migrations)
# ✓ 8 migrations completed successfully
```

### 4. Seed Database (Optional)

```bash
# Populate with test data
bun run db:seed
# OR
npm run db:seed

# Expected output:
# ✓ Created 5 test users
# ✓ Created 3 subscription plans
# ✓ Created 10 sample assets
# ✓ Database seeded successfully
```

### 5. Verify Database Setup

```bash
# Connect to Supabase and run a test query
# Use Supabase Studio at http://localhost:54321/project/default/editor

# Or via CLI:
psql -h localhost -p 5432 -U postgres -d postgres -c "\dt"
# Should list all tables
```

## Local Services

### Services Included in docker-compose.yml

| Service | Port | Purpose |
|---------|------|---------|
| Supabase | 54321 | Database & Auth |
| PostgreSQL | 5432 | Database backend |
| MinIO | 9000-9001 | S3-compatible storage |
| Redis | 6379 | Caching & sessions |

### Start Services

```bash
# Start all services in background
docker-compose up -d

# View logs
docker-compose logs -f

# Stop services
docker-compose down

# Remove all data (reset)
docker-compose down -v
```

### Access Local Services

```bash
# Supabase Studio
http://localhost:54321

# MinIO Console
http://localhost:9001
# Username: minioadmin
# Password: minioadmin

# Redis CLI
docker exec -it framic-ai-redis redis-cli
```

## Troubleshooting

### Issue: Docker services won't start

```bash
# Solution 1: Check if Docker is running
docker ps

# Solution 2: Check for port conflicts
lsof -i :54321  # Supabase
lsof -i :9000   # MinIO
lsof -i :6379   # Redis

# Solution 3: Remove old containers and restart
docker-compose down -v
docker-compose up -d
```

### Issue: Database migration fails

```bash
# Check Supabase logs
docker-compose logs supabase

# Reset database and try again
docker-compose down -v
docker-compose up -d
sleep 30
bun run db:migrate
```

### Issue: npm/bun install fails

```bash
# Clear cache
bun install --force
# OR
npm cache clean --force

# Reinstall
bun install
```

### Issue: Port already in use

```bash
# Find what's using the port
lsof -i :3000

# Kill the process
kill -9 <PID>

# Or change the port
PORT=3001 bun run dev
```

### Issue: TypeScript errors

```bash
# Rebuild TypeScript cache
bun run type-check

# Or delete cache
rm -rf .next
bun run build
```

### Issue: Git credentials not working

```bash
# Test SSH connection
ssh -T git@github.com

# If it fails, setup SSH keys
ssh-keygen -t ed25519 -C "your.email@example.com"
# Add to GitHub: https://github.com/settings/ssh/new

# Or use HTTPS with personal access token:
git config --global credential.helper store
```
